EduNovaAI SQL Project

 Project Overview

EduNovaAI is a Learning Management System (LMS) database project developed using MySQL. 
This project demonstrates database design and advanced SQL concepts through a real-world learning management system.

- MySQL Workbench
- SQL
- Git & GitHub
